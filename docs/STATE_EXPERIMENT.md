# D 的 V1/V2 状态实验

更新日期：2026-10-18。

## 研究问题

在固定 DQN、sparse 奖励、探索参数和环境交互预算下，比较：

- V1：11 维，包含 3 个动作危险标志、4 个朝向标志、4 个食物方向标志。
- V2：20 维，在原 11 维后追加归一化食物距离和蛇头周围 8 格局部占用环。

V2 是整体状态方案对比，不是距离与局部环的分别消融。
更多信息未必产生更好成绩；无差异或负结果同样需要报告。
完整索引以 [INTERFACE.md](INTERFACE.md) 的第 4 节为准。

## V2 编码

| 维度 | 信息 | 编码 |
|---|---|---|
| 0-10 | V1 全部信息 | 原语义保留 |
| 11 | 食物距离 | 曼哈顿距离 / (2 * (board_size - 1)) |
| 12-19 | 局部占用 | 前、前右、右、后右、后、后左、左、前左 |

占用环随蛇朝向旋转，蛇身或出界记 1，空格记 0；蛇尾按可腾出的格子记 0。
前、左、右三格分别与 danger_straight / danger_left / danger_right 一致。
V2 仍是局部压缩观测，不能完整描述远处蛇身拓扑，也不保证具有完整马尔可夫性。

状态描述的是行动后的当前环境。吃完食物并刷新后，距离与方向都指向新食物。
这修正了原预案“吃到食物那一步距离必为 0”的矛盾：新食物已出现时，强制置零会给出不一致观测。
满棋盘胜利、不刷新食物时距离为 0。奖励距离差仍比较同一颗旧食物，两者用途不同。

## 环境正确性修复

测试发现：移入旧蛇尾格时，原 _advance 先加入新头再移除旧尾；两者坐标相同时，
会从 occupied 集合误删新头。现改为先移出旧尾再加入新头，始终保证 occupied == set(body)。

此修复对 V1/V2 同时生效，可能改变涉及该局面的历史轨迹。
本次两个状态都从头训练，不直接拿修复前的旧模型成绩作为对照。
旧 checkpoint 的格式与维度加载兼容不变；“可加载”不代表修复前后任何轨迹都相同。

## 控制变量与参数量

默认正式设置：

| 项目 | 固定值 |
|---|---|
| 算法 / 奖励 | DQN / sparse |
| 棋盘、初始长度、每局上限 | 10x10、3、500 步 |
| 训练 seeds | 42、43、44 |
| 预算 | 每个模型 100,000 环境步 |
| 评估 | 每个模型 50 局，环境 seeds 10000-10049 |
| 探索 | 起点 1.0，下限 0.05，每环境步乘 0.9999 |
| 网络 | 两层隐藏层，每层 128 |
| 其他 | gamma=0.99，lr=0.001，batch_size=64，预热 1000，buffer=100000 |
| 目标网络 | 每 1000 次成功梯度更新硬同步 |
| 评估过程 | 纯贪心、不更新网络、不写回放池 |

hidden_dim 相同不代表参数量完全相同：默认 V1 为 18,435，V2 为 19,587，
多出 1,152 个输入层参数。实验 manifest 保存实际计数，报告必须说明此容量差异。
相同训练 seed 只是配对标签；输入层形状不同，不能假定两个网络的共有层初始化完全一致。
相同评估环境 seed 使开局随机条件可比，但策略改变后，轨迹和后续食物序列可能不同。

## 运行方式

先调试：

```powershell
.\.venv\Scripts\python.exe -m experiments.state_experiment.run --seeds 42 --total_steps 2000 --eval_episodes 3 --experiment debug_state
```

正式比较：

```powershell
.\.venv\Scripts\python.exe -m experiments.state_experiment.run --seeds 42 43 44 --total_steps 100000 --eval_episodes 50 --eval_seed 10000 --official --experiment state_v1_v2
```

脚本复用公共 train/evaluate，不复制训练循环；拒绝混入其他算法或 shaped reward。
V1 与 V2 分别评估，再在 comparison.json 汇总，避免放宽公共评估器的环境一致性检查。
不同状态使用同一组训练和评估种子，不挑选最佳训练 seed，不复用历史训练产物。

输出到 results/state_experiments/<唯一run>/：

```text
comparison.json        全部配置、路径、参数量、分组结果和执行状态
comparison.csv         每个状态、每个训练 seed 的模型评估摘要
logs/<run>/            训练 config / metrics / summary / checkpoint
evaluations/<run>/     独立评估 config / metrics / summary
figures/               从原始日志生成的图表
```

重生成图表：

```powershell
.\.venv\Scripts\python.exe -m experiments.state_experiment.plot --comparison results/state_experiments/<run>/comparison.json --bin_steps 5000
```

训练曲线按环境步分箱，先计算每个 seed 的完整局均值，再计算跨 seed 均值。
空箱不补零、不插值，只有所有 seed 都有数据的箱显示标准差带。
评估误差棒是“各训练 seed 模型均分”的总体标准差（ddof=0），
与“单模型 50 局得分标准差”不同；黑点保留各个模型的均分。

## 结论边界与后续

- 主要比较独立评估 mean_score，结合训练 seed 的波动、平均局长、截断率分析。
- 当前训练曲线包含探索，不是训练中各时点的独立贪心评估，不能单凭曲线宣称收敛或更快收敛。
- 只检验 V2 整体；要判断距离或局部环分别贡献多少，需后续 V2a/V2b 消融。
- 3 个训练 seed 的结果不能直接外推为普遍最优，也不能假装已有统计显著性结论。
- 只能提出与数据相容的原因假设；局部信息是否减少自围等行为需通过轨迹或视频进一步验证。
- 正式结果、逐 seed 表、图表与 PPT 素材在实验完成后记录到 [D_WORK_SUMMARY.md](D_WORK_SUMMARY.md)。
